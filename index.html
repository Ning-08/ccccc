GitHub Pages 4 步驟發布備忘錄

只需將此單一 HTML 檔案上傳至 GitHub，即可免費發布個人品牌作品集！

STEP 1

新建本地與 GitHub 倉庫

將此程式碼儲存為 index.html。前往 GitHub 點擊 New Repository 建立名為 portfolio 的公開倉庫。

STEP 2

執行 Git 推送指令

git init
git add index.html
git commit -m "Initial commit"
git branch -M main
git remote add origin [您的倉庫URL]
git push -u origin main
STEP 3

開啟 GitHub Pages 功能

進入專案頁面的 Settings ➔ 點選左側 Pages。在 Branch 選擇 main 並按 Save。

STEP 4

成功上線發布！

等待 1 至 2 分鐘，頁面頂部會出現綠色提示勾勾，您即可透過 https://yourname.github.io/portfolio 存取公開網站。
